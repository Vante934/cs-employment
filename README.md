## 📖 项目简介

**计算机行业就业数据可视化** 是一个基于 Web 的数据可视化项目，展示了计算机行业不同方向（前端、后端、人工智能、数据分析）的就业数据，包括城市分布、平均薪资、行业分布和热门岗位。

项目通过多维度图表展示，帮助求职者、在校学生和从业者直观了解行业现状和发展趋势，为职业规划提供数据参考。

## 📊 数据维度

### 四大就业方向

| 方向 | 说明 | 热门岗位 |
|------|------|----------|
| 🎨 **前端开发** | Web 前端、移动端、小程序 | 前端工程师、React 开发、Vue 开发 |
| ⚙️ **后端开发** | 服务端、数据库、架构 | Java 开发、Go 开发、Python 后端 |
| 🤖 **人工智能** | 算法、深度学习、NLP | 算法工程师、机器学习、AI 研究员 |
| 📈 **数据分析** | 数据挖掘、商业分析、大数据 | 数据分析师、数据科学家、BI 工程师 |

### 分析维度

- **城市分布** - 一线 / 新一线 / 二线城市就业热度对比
- **薪资水平** - 各方向、各城市、各年限薪资区间
- **行业分布** - 互联网 / 金融 / 教育 / 医疗等行业占比
- **热门岗位** - 需求量最高的岗位 Top 排行
- **历年趋势** - 近 5 年就业市场变化趋势

## 🚀 快速开始

### 方式一：直接查看（最简单）

直接打开 `index.html` 文件即可在浏览器中查看数据可视化效果，无需任何安装。

```bash
# 克隆项目
git clone https://github.com/Vante934/cs-employment.git
cd cs-employment

# 直接用浏览器打开
# Windows:
start index.html
# macOS:
# open index.html
# Linux:
# xdg-open index.html
```

### 方式二：本地服务器预览

```bash
# 使用 Node.js (需要安装 Node.js)
npx serve .

# 或使用 Python
python -m http.server 8000
```

然后访问 `http://localhost:8000` 即可查看。

### 方式三：更新数据（可选）

如需爬取最新数据，运行爬虫脚本：

```bash
# 安装 Python 依赖
pip install requests beautifulsoup4

# 运行爬虫
python crawler.py
```

爬虫会自动从配置的数据源抓取数据并更新 `employment_data.json`。

## 📊 数据说明

### 数据来源

**官方数据源：**
- 教育部大学生就业服务平台 (ncss.cn)
- 麦可思研究院就业蓝皮书 (mycos.com.cn)
- 工信部人才交流中心 (miitec.org.cn)
- 清华大学、北京大学等重点高校就业质量报告

**招聘平台：**
- 拉勾网
- 前程无忧
- 智联招聘
- BOSS 直聘
- 脉脉

### 数据统计说明

| 维度 | 统计方式 | 更新频率 |
|------|----------|----------|
| 城市分布 | 基于各平台公开的招聘数据统计 | 季度 |
| 薪资分布 | 基于岗位薪资范围取中位数统计 | 半年 |
| 行业分布 | 基于企业行业分类统计 | 年度 |
| 热门岗位 | 基于招聘需求量排序 | 月度 |

## 🕷️ 爬虫使用说明

### 配置数据源

编辑 `data_sources.json` 文件，添加或修改数据源：

```json
{
  "sources": [
    {
      "name": "示例数据源",
      "url": "https://example.com/jobs",
      "type": "web",
      "enabled": true
    }
  ]
}
```

### 运行爬虫

```bash
# 运行完整爬虫（所有启用的数据源）
python crawler.py

# 查看帮助
python crawler.py --help
```

> **注意：** 爬虫脚本可能会因网站结构变化而需要更新。请遵守各网站的 robots.txt 协议和使用条款，合理控制请求频率。
