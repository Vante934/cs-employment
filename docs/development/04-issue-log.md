- **优先级**: P0(阻塞)/P1(高)/P2(中)/P3(低)
- **状态**: 发现/分析中/已解决/已验证/已关闭/延期

- **解决方案**: 如何修复
- **验证方法**: 如何确认已修复

### DEBT-001: 异步任务无持久化

**优先级**: P2  
**引入日期**: 2025-01-XX  
**原因**: 首期简化实现

**问题描述**:

- 无任务队列和优先级

- 或使用轻量级任务队列

**触发条件**:
- 文件量 > 100/天
- 用户频繁重启服务

### DEBT-002: FAISS 索引删除不彻底（F05-A1 已解决，见 ADR-010）

**解决方式**: 改用 `IndexIDMap2` 并通过 `remove_ids` 真正删除向量；旧 `IndexFlatIP` 索引在加载时迁移，孤儿向量被丢弃。原问题会导致删除后重启时索引被清空，实际严重程度高于原定的 P3。

**原记录**:

**优先级**: P3  
**引入日期**: 2025-01-XX  
**原因**: FAISS 限制

**问题描述**:
FAISS 删除向量时只能标记为无效，不能真正删除，索引文件会持续增长。

**影响**:
- 长期使用后索引文件较大
- 影响加载速度

**计划改进**:
- 定期重建索引（如每月一次）
- 或切换到支持真删除的向量库（如 ChromaDB）

**触发条件**:
- 索引文件 > 1GB
- 加载时间 > 5秒

## 风险清单

### RISK-001: LLM 调用成本

**优先级**: P2  
**风险等级**: 中

**风险描述**:
每个文件需要调用 LLM 生成摘要和关键词，大量文件时成本较高。

**影响范围**:
- 用户如果使用 OpenAI API，成本可能较高
- 解析速度受 API 速率限制

**缓解措施**:
1. 使用缓存（相同文件不重复调用）
2. 提供配置选项，允许禁用摘要生成
3. 支持使用本地模型（如 Llama）

**触发条件**:
- 文件数 > 100
- 使用付费 API

**监控指标**:
- LLM 调用次数
- Token 消耗量

---

### RISK-002: 向量检索准确度不足

**优先级**: P2  
**风险等级**: 中

**风险描述**:
sentence-transformers 的中文效果可能不如 OpenAI Embeddings，导致检索召回率低。

**影响范围**:
- 用户查询时找不到相关资料
- 降低用户体验

**缓解措施**:
1. 准备中文优化模型作为备选
2. 实现混合检索（向量 + 关键词）
3. 允许用户反馈检索结果

**触发条件**:
- 中文查询召回率 < 60%
- 用户投诉较多

**验证方法**:
- 准备中文测试集
- 测量 top-5 召回率

---

### RISK-003: 文件解析器失败率高

**优先级**: P1  
**风险等级**: 中

**风险描述**:
PyPDF2、python-docx 等库对复杂格式的支持有限，可能出现解析失败。

**影响范围**:
- 部分文件无法入库
- 用户需手动处理

**缓解措施**:
1. 提供降级方案（如仅提取纯文本）
2. 明确文档说明不支持的格式
3. 收集失败样本，逐步优化

**触发条件**:
- 解析失败率 > 20%

**监控指标**:
- 各格式的成功率
- 失败文件的类型分布
